# Mohamed Ben Bettaieb — Personal Portfolio

A framework-free portfolio site for Mohamed Ben Bettaieb, software engineer, technical lead, competitive programmer, and DSA mentor.

## Run locally

From this folder, start any static file server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Before deploying

The contact email is configured in `index.html` as:

```html
mailto:mohamedbettaieb17@gmail.com
```

The site also links to Mohamed's LinkedIn, GitHub, Upwork, LeetCode, and Codeforces profiles.

The profile photo is stored as `mohamed-profile.png` and can be replaced with another image using the same filename.

The site is static and can be deployed to GitHub Pages, Netlify, Vercel, or any web host that serves HTML/CSS/JavaScript.
